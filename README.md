# Teen Mental Health Segmentation Using K-Means Clustering

## Project Overview
This project uses K-Means Clustering, an unsupervised machine learning algorithm, to analyze teen mental health data and identify distinct groups based on behavioral and psychological characteristics. The objective is to uncover hidden patterns within the dataset and provide meaningful insights for mental health analysis.

## Objectives
- Analyze teen mental health data
- Perform data preprocessing and exploratory data analysis
- Apply K-Means Clustering
- Determine optimal number of clusters
- Visualize and interpret cluster patterns

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Technique
- K-Means Clustering

## Outcomes
- Identified distinct mental health groups
- Visualized cluster distributions
- Generated insights from unsupervised learning
